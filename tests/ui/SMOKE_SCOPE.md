# UI Smoke scope (Playwright + Pytest)

Цель: быстрый прогон критичных UI-путей без авторизации (smoke), чтобы понять “сайт жив / основные элементы на месте”.

База: https://kp.ktsf.ru/

## Набор тестов (7)

1) `test_homepage_opens_and_has_create_button`
- Что проверяет: главная страница открывается, есть кнопка “Создать объявление”.
- Зачем: базовая доступность UI и главный CTA.

2) `test_search_input_exists_and_accepts_text`
- Что проверяет: на главной есть поле поиска, в него вводится текст.
- Зачем: критичная функция поиска доступна пользователю.

3) `test_categories_button_exists`
- Что проверяет: на главной видна кнопка/ссылка “Все категории”.
- Зачем: навигация по каталогу доступна.

4) `test_login_button_opens_auth`
- Что проверяет: по кнопке “Войти” открывается форма/модалка авторизации.
- Зачем: вход в систему доступен (без проверки логина).

5) `test_create_ad_requires_auth_opens_auth`
- Что проверяет: при попытке “Создать объявление” (гостем) открывается авторизация.
- Зачем: защищённый сценарий корректно требует логин.

6) `test_open_first_card_opens_details`
- Что проверяет: кликабельна первая карточка объявления и открываются детали.
- Признаки успеха: меняется URL ИЛИ появляется индикатор страницы деталей (заголовок/описание/CTA).
- Зачем: пользователь может открыть карточку объявления.

7) `test_actions_on_details_require_auth_when_available`
- Что проверяет: на странице деталей при клике по действиям (например “Написать/Позвонить/Контакты/Избранное/Откликнуться/Купить/Заказать” — что доступно) открывается авторизация.
- Если CTA на странице деталей нет — тест корректно пропускается (skip) как допустимый вариант UI.
- Зачем: защищённые действия требуют авторизацию.

## Запуск

### 1) Запуск UI smoke
```bash
./run_tests.sh

2) Только UI тесты

pytest -q tests/ui

3) Allure отчёт

После прогона скрипт генерирует отчёт и поднимает сервер Allure.
Если не открылось автоматически:

VS Code → PORTS → 4040 → открыть в браузере.

Примечания по стабильности

Используются “мягкие” локаторы (role/text/placeholder), чтобы переживать мелкие правки верстки.

Перед кликами пробуем закрыть баннеры (cookie/ok/close), если они перекрывают элементы.
